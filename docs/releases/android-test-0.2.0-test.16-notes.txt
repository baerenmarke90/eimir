Adds the shared diary under Moments: write with a visible date, add and reorder photos, and optionally add a title or tags. Saved entries open in a calmer reading view with natural paragraphs.

Unsaved text, dates, tags and selected photos can be recovered on the same device for up to seven days without changes. Local drafts are separate from sharing an entry with your partner. Interrupted saves preserve their original request identity to avoid duplicate entries.

Includes the merged diary implementation and its completed browser-test correction from PR #1458, together with the existing App Updates channel and previous client improvements.

Install Build 16 through App Updates. The package, original signing identity and persistent test installation remain the same. Actual device installation, session continuity and OS email-link handling still require practical acceptance.
