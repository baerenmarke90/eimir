## Evidence and limits

The live fictional demo was inspected at the available desktop width (1363×936 CSS px). Its deployed SHA was not independently verified. Mobile 360/390/430 comparisons and Dark mobile evidence came from the earlier fixture audit, not from a resized live browser.

The PDF/overview are static target studies with fictional names, dates and existing demo images. They illustrate content dominance, hierarchy and rhythm; they cannot establish real focus, keyboard, Back, persistence, native accessibility or user comprehension. Their calm layouts are not pixel locks and do not justify empty implementations.

Selected token-pair calculations supported role decisions, including avoiding muted Light helper text and white labels on bright Dark coral. They were not a full accessibility certification. Each implementing slice must validate its actual foreground/background/media pairs in both themes.

The calibration introduced no runtime code, production writes, new provider, remote font dependency or entitlement change. Font files used the repository's SIL Open Font License basis; imagery reused documented fictional demo assets. The source package retains font license and image-provenance records. No source binaries are imported by this documentation integration.
