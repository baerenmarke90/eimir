# after an install or an update does not interpret it before Android has

# covered here.
#
# This file is hand-written with wildcards, not recorded: the release build does
# not shrink or rename classes, so these names are stable. A recorded profile
# (macrobenchmark) would be narrower; replace this file with one when the app
# has a benchmark module.
