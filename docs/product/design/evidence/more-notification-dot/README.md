# More navigation notification dot

Evidence for the larger, higher-contrast unread dot on the More navigation item.

| File | State |
| --- | --- |
| `compact-dark.webp` | Compact, 390 px, Dark, More inactive, four unread notifications |
| `compact-light.webp` | Compact, 360 px, Light, More active, four unread notifications |
| `expanded-dark.webp` | Expanded, 1280 px, Dark, More active |

Captured from the local Web client and development backend with the fictional
demo Space. The native-only `@capacitor/haptics` module was stubbed for this
browser run because the shared local dependency folder predates it.

Not covered: physical Android device and large system text.
