## Mobile Interaction Contract

- The task is finding one useful starting point. On Wir, the actual
  relationship area comes first. The optional introduction has one launch
  action and immediately reachable session and permanent dismissal choices.
- The guide is a secondary page with the common Back row and a single group
  of four destination links. It uses the shared reading width on Expanded Web.
  Links wrap on Compact and require no typing, gesture or completion order.
- Each choice opens the real surface. One local hint explains an available
  action. The private choice opens Notes directly, with the existing audience
  information visible. Editing, consent, paid capabilities and authorization
  are owned by the destination.
- The guide is local UI. Existing loading, empty, cached, offline and error
  states still represent the destination's data. Wir shows the offer when the
  dashboard content is ready. Returning to the guide uses the same task origin
  and restores the topic's focus and reading position.
- The hint moves 4 px and fades in over the standard 180 ms token on a selected
  destination's arrival. Quick Create uses the existing sheet timing. Reduced
  motion skips the hint animation and uses the shared sheet fallback.
- Review the launch, guide and private landing on Compact, the guide on
  Expanded, both appearances, large text, keyboard focus and reduced motion.
