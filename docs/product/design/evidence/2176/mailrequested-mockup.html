User goalI asked for a link and it did not arrive or did not work: try again or fix the address without leaving the app.

Typing / keyboardResend needs no typing (same address kept in memory only). Keyboard opens only after "Andere Adresse verwenden".
StatesLoading: button text "Anfrage wird gesendet …", same width. Success: the status area is updated and keeps focus (screen reader announces it). Error: existing inline error pattern above the buttons. Offline: the request fails with the existing offline error; buttons stay. Empty: n/a.
PrivacyNeutral wording stays (no account-existence oracle). The echoed address is the one the person typed on this device; never from the server. Snackbar has no host or token.
Large text / narrowFull-width stacked buttons wrap; no fixed heights; nothing needs horizontal scroll at 320 px.
MotionNotice text swap uses the existing fade; reduced motion: instant swap. No new animation.
ExpandedSame card, buttons may sit side by side; meaning unchanged.
ReuseNeutralMailResult, BackToSignIn, button variants, postSnackbar. No new component or token.
