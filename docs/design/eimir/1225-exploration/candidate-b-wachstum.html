RecognizabilityNeeds the most relearning: new silhouette, new material. Differentiates furthest from generic dating-app UI once learned.
Contrast (indicative)#3D95D0-anchored accent on white ≈3.4:1 for the blue end — large UI only; the green end #4FAE9E ≈2.9:1, so body text should sit on the darker leaf tone, not the raw gradient. Flagged for Phase C.
FeasibilityMedium risk: asymmetric radii and duotone fills are easy in CSS/SVG, but every icon needs its own bespoke path rather than a shared primitive.
