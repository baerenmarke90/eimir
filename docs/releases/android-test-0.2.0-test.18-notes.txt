Adds automatic places from selected photos when you save a shared Memory or HeartMoment. This is Free/Core. The account-wide “Automatically add places” setting starts on; switching it off affects future photos and keeps existing places.

Private HeartMoments never create shared places, including when shared later. Photos without GPS remain normal photos. Stored images and thumbnails still discard EXIF. You can correct a place or remove its link from a moment; retries preserve those choices. Maps opens only when you choose it.
