# Pro showcase sample photos

Fictional sample photos for the animated Pro showcase scenes (#2310). They are
never a couple's own content. Each file is a WebP derivative (longest edge
480 or 760 px) of a curated demo asset in `backend/demo_assets/`, whose
`manifest.json` holds the full provenance. All five are Pixabay photos
published before 2019-01-09 under CC0 1.0 Universal (licence basis:
<https://pixabay.com/service/terms/>, checked 2026-08-31 for the demo set).
No attribution is required. Source URLs are provenance only and are never
loaded by the app.
