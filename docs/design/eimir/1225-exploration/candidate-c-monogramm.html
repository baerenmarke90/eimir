RecognizabilityMedium-high: the legible “e” ties the mark directly to the name, which helps first-time recognition, but it is a bigger visual change than Candidate A.
Contrast (indicative)White “e” on #7C5FE0→#7FABF6 gradient stays >4.5:1 across the whole gradient range. Filled icon glyphs on white tiles use solid #4B3BB8 ≈8.6:1. Formal WCAG sign-off is a Phase C deliverable.
FeasibilityLow-medium risk: the circles reuse Candidate A's geometry, but the “e” needs to stay legible at every size — the 16px favicon sample above is the risk case to test first.
